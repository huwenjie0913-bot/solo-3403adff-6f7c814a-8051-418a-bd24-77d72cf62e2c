# 皮带传动布置校核（Belt Drive Layout Checker）

设备改造场景下的皮带传动布置校核网页：在 Canvas 上放置主动轮、从动轮、
惰轮/张紧轮和矩形护罩，按绕行顺序生成开口/交叉带路径；每次移动实时重算
切点、包角、带长、转速、张力与张紧行程，直接标出护罩干涉、非交叉模式下
的带段相交、包角不足、张力超限、张紧行程不足等问题。点告警可联动高亮
相关轮、带段与计算依据；方案可叠加比较，导出带尺寸标注的 SVG 和可再次
导入的 JSON。

## 多级传动模式（两/三级皮带）

顶部“新回路”可在同一画布建立多条独立皮带回路（颜色区分，左侧回路卡片
可切换“当前回路”编辑绕行顺序、功率、效率及 μ/许用张力/包角/张紧等高级
参数）。把多个带轮“归到同一根共享轴”（属性面板的“所属轴/归并到”），
即组成两级或三级传动：

- 后端沿“回路 → 共享轴 → 下一回路”图传播转速与方向：`n从 = n轴·d主/d从`，
  交叉段反转；同一共享轴上各级带轮转速必须一致，矛盾时报
  `SHAFT_SPEED_CONFLICT`/`SHAFT_DIR_CONFLICT`，并指出具体轴与相关回路。
- 每条回路独立复用既有公切线、包角、张力与干涉计算；功率按效率传递
  `P出 = P入·η`。
- 共享轴汇总：轴上扭矩 `T = 9550P/n`（取最大一级与许用扭矩比较）和
  各回路紧/松边张力的**径向矢量合力** Fr（与许用径向载荷比较，
  `SHAFT_TORQUE`/`SHAFT_RADIAL`）。
- 拖动共享轴时轴上带轮整体移动并实时重算；轴可锁定（🔒 顶部“锁定轴位”
  只锁非张紧轮轴，便于只调整其余轴位和轮径试排）。
- 点中轴、汇总表行或告警联动高亮：高亮该轴全部带轮与所属回路（其余回路
  变暗），属性面板/汇总表列出轴上扭矩、径向合力和各级输入输出转速。
- SQLite 方案带版本号（覆盖保存自增），JSON 导入导出与 SVG 均保留
  共享轴、回路编号/颜色和计算结果（各级功率、转速、张力与轴载荷）。
- 旧版单回路 JSON 与浏览器自动存档可平滑迁移：每个带轮自动获得独立轴并
  归入“回路 1”。

- 后端：Python + Flask（几何计算在服务端完成）
- 存储：SQLite（`belt/belt.db`，首次启动自动建表）
- 前端：原生 JavaScript + Canvas，无构建步骤

## 启动

标准环境：

```bash
python3 -m pip install -r requirements.txt
python3 app.py
# 打开 http://localhost:5000  （端口可用 PORT=xxxx python3 app.py 覆盖）
```

无 pip 的受限环境：仓库自带 `.pylibs/lib/python3.*/site-packages`（Flask 及其
依赖），`app.py` 在系统 Python 找不到 Flask 时会自动加载，直接
`python3 app.py` 即可。也可手动指定：

```bash
PYTHONPATH=.pylibs/lib/python3.11/site-packages python3 app.py
```

## 使用要点

- 顶部工具：选择、主动轮、从动轮、惰轮、张紧轮、矩形护罩；轮/护罩按下后
  拖动可指定直径或矩形尺寸，单击则用默认尺寸放置。
- 滚轮缩放、右键/中键/Alt+左键平移，`F` 适配视图，`Delete` 删除选中。
- 左侧“绕行顺序”按皮带实际绕入顺序列出全部轮（可拖拽排序），可逐段勾选
  “交叉”；两轮布置可用顶部“开口带/交叉带”一键切换。
- “锁定轮位”后只允许拖动张紧轮试算；单个轮也可在属性面板单独锁定。
- 右侧告警列表点击任一告警，画布高亮关联轮与带段，底部显示该判定的
  计算依据（公式与代入数值）。
- 方案库存入 SQLite；勾选两条方案后“叠加比较”：指标差值表 + B 方案虚线
  叠加到当前画布。
- SVG 导出含中心距、段长、包角、转速和张力标题块；JSON 可再次导入。

## 校核内容

| 类别 | 判定 |
|---|---|
| 几何 | 轮体重叠、带段擦碰非相邻轮、非交叉模式带段相交、交叉数奇偶（绕向闭合） |
| 包角 | 各轮沿转向的实际包角 < 最小包角 |
| 护罩 | 轮体与 OBB 重叠；各带段/轮弧到护罩间隙 < 安全间隙或直接碰撞（告警 refs 定位到具体带段） |
| 运动 | n从 = n主·d主/d从、交叉段反转转向；目标转速/转向偏差 |
| 张力 | v=πdn/60000；Fe=1000P/v；F2=Fe/(e^μθ−1)；F1=Fe+F2；F0≈(F1+F2)/2；Pmax=v[F](1−e^−μθ)/1000 |
| 张紧 | 张紧轮内压 2 mm 数值试算带长缩短率，补偿带伸长(默认1%)+安装余量(跨距和0.5%)所需行程 vs 可用行程 |

## API

- `POST /api/analyze` — 入参完整方案 JSON，返回切点/包角/带长/张力/告警
- `POST /api/compare` — `{a, b}` 两方案指标对比
- `GET/POST /api/schemes`、`GET/PUT/DELETE /api/schemes/<id>` — SQLite 方案库
